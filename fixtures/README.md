# Fixture corpus provenance

This collection contains 12 genuine research papers related to sentence embeddings, retrieval, RAG, scientific claim verification, and evaluation. Each JSON record identifies the title, cited authors, year, arXiv identifier, subtopic, and canonical arXiv URL. The included text is a short verbatim abstract excerpt (at most 25 words per paper). Full papers are not included. Evidence locations are therefore labeled `Abstract (verbatim excerpt)` rather than assigned invented page numbers.

The excerpts were selected from the linked arXiv abstract records. See `papers.json` for the source text and per-paper provenance.
